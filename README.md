# AI-Powered IFRS & IAS Research Assistant

An AI-powered accounting standards research assistant using
Retrieval-Augmented Generation (RAG).

## Project Objective

The objective of this project is to develop an AI assistant
that helps accounting students and professionals find and
understand relevant IFRS and IAS guidance.

## Planned Architecture

React
    ↓

    ↓

    ↓
Embeddings
    ↓

    ↓

    ↓
Answer + Sources
